Set up editing

  1. On GitHub, create a fine-grained personal access token:
    • Repository access: Only select repositories → Schippeaux.github.io
    • Repository permissions: Contents → Read and write
    • Expiration: your choice (you can replace it later from the editor)
  2. Paste it below and choose an editor password (at least 12 characters). The token is stored encrypted with this password; it is never sent anywhere except GitHub.
